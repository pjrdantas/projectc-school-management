# Histórico Escolar - Angular Material

Projeto Angular independente gerado a partir da tela de Histórico Escolar do arquivo original.

## Como executar

```bash
npm install
npm start
```

Abra no navegador o endereço exibido pelo Angular CLI, normalmente `http://localhost:4200`.

## O que foi convertido

- Layout de histórico escolar do Ensino Fundamental.
- Identificação da unidade escolar.
- Identificação do aluno.
- Tabela por componente curricular, ano, notas, médias e frequência.
- Situação por ano com chips clicáveis.
- Observações, assinaturas e botão de impressão / salvar PDF.

Os dados estão mockados em `src/app/app.component.ts` para facilitar a ligação futura com sua API Java.
