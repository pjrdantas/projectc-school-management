# Diário de Classe - Angular Material

Projeto Angular independente gerado a partir da tela de Diário de Classe do arquivo original.

## Como executar

```bash
npm install
npm start
```

Abra no navegador o endereço exibido pelo Angular CLI, normalmente `http://localhost:4200`.

## O que foi convertido

- Layout do diário de classe escolar.
- Cabeçalho com dados da escola, ano letivo, turma, disciplina e professor.
- Grade de frequência com 31 dias.
- Conteúdo ministrado.
- Avaliações.
- Observações e assinatura do professor.
- Botão de impressão / salvar como PDF.

Os dados estão mockados em `src/app/app.component.ts` para facilitar a ligação futura com sua API Java.
