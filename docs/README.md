## Historico

A pasta `historico/` guarda copias organizadas de documentos e scripts antigos/desatualizados. Ela existe para consulta e rastreabilidade, nao como fonte ativa de implementacao.

Alguns documentos antigos tambem permanecem no caminho original para reduzir conflitos de merge e preservar compatibilidade com referencias existentes, mas a orientacao atual e sempre partir dos documentos ativos listados acima.
